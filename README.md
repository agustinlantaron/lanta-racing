# Lanta Racing

Sitio estático de Lanta Racing (Agustín Lantaron).

- `index.html`: la página completa.
- `assets/`: cuadros del auto para el scroll (escritorio `s*.webp`, celular `m*.webp`) y la foto de Agustín.

No necesita compilación. En Vercel: Framework Preset "Other", sin build command, output en la raíz.
